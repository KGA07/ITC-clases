🔢 El teclado 4x4

  • Un teclado matricial 4x4 tiene 16 teclas dispuestas en 4 filas y 4 columnas. Gracias a esa matriz, con solo 8 pines (4 de fila y 4 de columna) la placa puede saber qué tecla se presionó.
  • La lectura se hace por barrrido: la placa activa una fila por vez y detecta en qué columna hay contacto. Ese trabajo ya lo hace la librería Keypad por nosotros.
  • · 16 teclas: números del 0 al 9 y símbolos.
  • · 8 pines: 4 filas (R1-R4) y 4 columnas (C1-C4).
  • · Solo 8 pines para leer 16 teclas: a esto se llama multiplexado.
  • · La librería Keypad se encarga del barrido de filas y columnas.

📦 Instalación con el gestor de librerías

  • Las librerías son código ya escrito que reutilizamos para no reinventar la rueda. Se instalan desde el IDE en Programa → Incluir librería → Administrar bibliotecas, buscando Keypad.
  • Una vez instalada, en el código se la importa con #include <Keypad.h> y se configura el mapa de teclas y los pines de filas y columnas.
  • · Gestor: Herramientas → Administrar bibliotecas → buscar Keypad → instalar.
  • · #include <Keypad.h> importa la librería.
  • · Se define el arreglo de teclas (chars) y los pines de fila/columna.
  • · keypad.getKey() devuelve la tecla presionada o vacío si no hay.

🧵 String, char y matrices

  • char guarda un solo carácter (una tecla). String guarda una cadena de texto y permite sumarlas con +. Las matrices son arreglos de datos del mismo tipo, y en el teclado se usan para definir el mapa (por ejemplo, un char con 16 posiciones).
  • Con String podés ir concatenando las teclas que se presionan y mostrar la secuencia: como un marcador de contraseña o de número de teléfono.
  • · char tecla; guarda un carácter.
  • · String texto; guarda cadenas y las suma con +.
  • · char teclas[4][4]: matriz de 4x4 con el mapa del teclado.
  • · Para comparar cadenas usás strcmp() o == entre Strings.

⚖️ strcmp() y comparación

  • strcmp(cadena1, cadena2) compara dos cadenas de caracteres: devuelve 0 si son iguales. Es la función por debajo de la comparación de contraseñas o códigos.
  • Con las Strings de Arduino, la comparación directa con == funciona igualmente. En este curso comparamos el texto ingresado contra un código esperado para armar un candado digital.
  • · strcmp devuelve 0 cuando las cadenas son iguales.
  • · Códigos de acceso: una cadena esperada y una ingresada.
  • · Con String de Arduino: if (textoIngresado == "1234")
  • · Ojo con mayúsculas: 'A' no es igual a 'a'.

🙌 Actividad práctica

Candado digital con teclado

Conectá el teclado 4x4 y programá un candado que abra un LED al ingresar el código correcto.

  1. Conectá los pines de columnas (C1-C4) a los pines digitales 5, 4, 3, 2 y las filas (R1-R4) a los pines 9, 8, 7, 6.
  2. Instalá la librería Keypad desde el gestor de bibliotecas.
  3. En el código definí el mapa: char teclas[4][4] = { {'1','2','3','A'},{'4','5','6','B'},{'7','8','9','C'},{'*','0','#','D'} };
  4. Configurá filas y columnas y creá: Keypad teclado = Keypad(makeKeymap(teclas), filas, columnas, 4, 4);
  5. En setup(): Serial.begin(9600); pinMode(13, OUTPUT);
  6. En loop(): char tecla = teclado.getKey(); y si hay, mostrala con Serial.println(tecla);
  7. Sumá la tecla a un String y comparalo contra "1234" con ==.
  8. Si coincide, encendé el LED del pin 13 y avisá por Serial "Acceso concedido"; si no, avisá "Codigo incorrecto" y vaciá el String.
  9. Probá con el código correcto y con uno equivocado.

Entrega: Captura del Serial mostrando las teclas presionadas y el acceso concedido/denegado.
