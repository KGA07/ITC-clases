📦 Componentes del kit de desarrollo

  • El kit de desarrollo es tu caja de herramientas electrónica. Además de la placa Arduino, tiene componentes pasivos y activos que vas a combinar en cada proyecto.
  • Separar y reconocer cada componente por su forma y función es el primer paso para armar circuitos sin errores: a lo largo del curso vas a usar cada uno de estos elementos.
  • · Placa Arduino (Uno o Nano): el cerebro del proyecto.
  • · Protoboard: tabla para armar circuitos sin soldar.
  • · Cables de conexión (jumpers) y cables USB.
  • · LEDs, resistencias y pulsadores: los básicos de todo circuito.
  • · Sensores, displays y motores: se incorporan clase a clase.

💻 El IDE de Arduino

  • El IDE (Entorno de Desarrollo Integrado) es el programa donde escribís, revisás y cargás el código a la placa. Se descarga gratis desde la web oficial de Arduino.
  • Su ventana tiene un editor de texto central, una barra de herramientas con los botones de Verificar y Cargar, y una zona inferior donde aparecen mensajes y errores.
  • · Editor: el área blanca donde se escribe el programa (sketch).
  • · Botón Verificar (✓): compila el código y avisa si hay errores de sintaxis.
  • · Botón Cargar (→): compila y envía el programa a la placa por USB.
  • · Consola: muestra el progreso y los mensajes de error o éxito.

📝 Por qué usar un sketch

  • En Arduino, cada programa se llama sketch. Un sketch se guarda en una carpeta con el mismo nombre y tiene la extensión .ino. Mantener la carpeta y el archivo con el mismo nombre evita errores al abrir los proyectos.
  • · Guardá cada práctica con un nombre claro, por ejemplo: semaforo_clase9.
  • · Un sketch puede tener varias pestañas: el programa principal y otras funciones.
  • · El IDE exige que el archivo principal y su carpeta se llamen igual.

🖱️ TinkerCad: el simulador del curso

  • TinkerCad es una plataforma web gratuita de Autodesk que permite armar circuitos virtualmente: arrastrás la placa, los componentes y los cables, escribís el código y ves el resultado simulado. Es perfecta para experimentar antes de tocar el hardware real.
  • En cada clase vamos a diseñar el circuito en TinkerCad y después lo vamos a construir en la protoboard física.
  • · Entrá a Tinkercad.com con tu cuenta de correo de la institución.
  • · En la sección Circuitos encontrás el espacio de diseño.
  • · Simular no rompe nada: podés probar sin miedo a quemar componentes.
  • · Compartí el circuito virtual por link cuando te lo pida el docente.

⚙️ Instalación del IDE paso a paso

  • Descargá el IDE 2 desde la página oficial de Arduino, instalá el archivo siguiendo los pasos del asistente y dejalo en el escritorio. No hace falta configuración especial: el IDE se conecta solo a la placa cuando la enchufás por USB.
  • Si la placa no aparece en el IDE, revisá el cable USB (usá uno que transmita datos, no solo cargue) y probá otro puerto.
  • · Descargá desde arduino.cc el instalador para tu sistema operativo.
  • · Aceptá la instalación completa con drivers de USB.
  • · Conectá la placa y verificá que Windows la reconozca.
  • · En Herramientas → Placa, seleccioná el modelo correcto (Uno o Nano).

🙌 Actividad práctica

Inventario del kit por parejas

Hacé un inventario completo del kit de desarrollo que te corresponde y anotá cada elemento.

  1. Vacía el contenido del kit sobre la mesa y acomodalo en grupos: placas, resistencias, LEDs, cables, sensores.
  2. Contá cuántas unidades hay de cada componente y registralo en una tabla.
  3. Identificá el modelo de Arduino del kit y anotá su nombre.
  4. Guardá todo en su lugar siguiendo el orden original.
  5. Abrí el IDE y en Herramientas → Placa seleccioná el modelo que registraste.

Entrega: Tabla de inventario del kit en el cuaderno con la cantidad de cada componente.
