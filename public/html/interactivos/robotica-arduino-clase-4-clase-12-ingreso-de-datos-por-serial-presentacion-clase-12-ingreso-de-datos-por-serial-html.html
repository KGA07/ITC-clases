Ingreso de datos por Serial

Tu placa no solo habla: también escucha. Vas a enviarle datos desde el Monitor Serie, a leer caracteres con Serial.read() y números completos con Serial.parseInt() para controlar tus circuitos desde el teclado.

🔁 La comunicación es de ida y vuelta

  • En la clase anterior viste cómo la placa envía datos a la PC. Pero la comunicación te permite también lo contrario: vos escribís un dato en el cuadro superior del Monitor Serie y, al presionar Enviar, ese dato viaja hacia la placa.
  • La placa recibe los datos por el canal Serial y puede usarlos para decidir qué hacer: prender un LED, cambiar un tiempo o mover un motor.
  • · Escribís en el campo superior del monitor y presionás Enviar.
  • · Los datos viajan por el mismo cable USB.
  • · La placa lee el dato y puede usarlo en su lógica.
  • · Para revisar si llegó algo, usás Serial.available().
Hecho con dedicación · @gustavokempe

📥 Serial.available() y Serial.read()

  • Serial.available() devuelve la cantidad de bytes que llegaron y están esperando para leerse. Serial.read() lee un byte (un carácter) de esa cola de datos entrantes.
  • La receta clásica: if (Serial.available() > 0) { char tecla = Serial.read(); ... } para actuar solo cuando haya datos.
  • · Serial.available() > 0 indica que hay datos esperando.
  • · Serial.read() devuelve un carácter (por ejemplo '1' o 'a').
  • · Esperar con available() evita leer datos vacíos.
  • · Los caracteres se pueden comparar: if (tecla == 'a') { ... }
Hecho con dedicación · @gustavokempe

🔢 Serial.parseInt()

  • read() lee de a un carácter, lo que complica recibir números de varios dígitos. Serial.parseInt() resuelve el problema: lee la secuencia y la convierte en un número entero listo para usar.
  • Por ejemplo, si enviás 255, parseInt() te devuelve el número 255 (y no tres caracteres sueltos). Ideal para ingresar valores de brillo, tiempos o posiciones.
  • · int valor = Serial.parseInt();
  • · Convierte la tira de dígitos recibida en un entero.
  • · Es bloqueante si no llega ningún número: cuidado con delays.
  • · Ideal para valores como tiempos y brillos.

🎮 Aplicaciones del ingreso de datos

  • Con el ingreso por Serial podés hacer tus primeros controles remotos por teclado: un comando para cada acción. Esto se llama protocolo simple de comandos y es la base de muchos sistemas reales.
  • Una buena práctica es mostrar un menú de opciones en el monitor para guiar al usuario: la placa imprime qué opciones hay y vos respondés por teclado.
  • · Menú: la placa imprime "1=Rojo 2=Verde 3=Apagar".
  • · Vos escribís el número y presionás Enviar.
  • · La placa compara la entrada y ejecuta la acción.
  • · Desde acá llegás en pocas clases a controlar motores y displays.

🙌 Actividad práctica

Control remoto de un LED por teclado

Programá un LED que responda a comandos enviados desde el Monitor Serie.

  1. Conectá un LED con su resistencia al pin 9 (PWM) y GND.
  2. En setup(): Serial.begin(9600); pinMode(9, OUTPUT); Serial.println("Envia 0=apagar 1=prender 2=parpadear");
  3. En loop(): if (Serial.available() > 0) { int cmd = Serial.parseInt();
  4. Con if (cmd == 0) apagá: analogWrite(9, 0);
  5. Con if (cmd == 1) prendé a máximo: analogWrite(9, 255);
  6. Con if (cmd == 2) parpadeá: tres ciclos de HIGH/LOW con delay(200).
  7. Agregá un comando extra que acepte un valor de 0 a 255 para graduar el brillo: analogWrite(9, cmd); usando parseInt.
  8. Enviá cada comando desde el monitor y verificá la respuesta del LED.

Entrega: Captura del Monitor Serie con los comandos enviados + foto del LED respondiendo.
