🔘 El pulsador y sus patas

  • El pulsador (o botón táctil) es un componente que cierra un circuito cuando lo presionás. Tiene cuatro patas conectadas de a pares por dentro: las dos de arriba son un mismo contacto y las dos de abajo el otro.
  • En la protoboard se inserta sobre el canal central, cruzando los dos bloques, para que cada par de patas quede en filas distintas y puedas cablear por separado.
  • · Las patas de un mismo lado están conectadas entre sí por dentro.
  • · Cruzás el canal central para separar los dos contactos.
  • · Al presionar, se conectan los dos lados del pulsador.
  • · Es una entrada: le dice a la placa presionado o no presionado.

🔍 digitalRead()

  • digitalRead(pin) devuelve el estado digital de un pin: HIGH (5V) o LOW (0V). Con un pulsador, el circuito clásico usa una resistencia pull-down que mantiene el pin en LOW; al presionar, el voltaje sube a HIGH.
  • En el código, guardamos la lectura en una variable: int estado = digitalRead(pin); y después decidimos qué hacer según ese valor.
  • · digitalRead(2); lee el estado del pin 2.
  • · Con pull-down: reposo = LOW, presionado = HIGH.
  • · La resistencia pull-down (10 kΩ) evita lecturas flotantes.
  • · Combinado con Serial, podés ver el estado en el monitor.
Hecho con dedicación · @gustavokempe

🔀 La estructura if()

  • if(condicion) { ... } permite ejecutar un bloque solo si la condición es verdadera. Es la forma de tomar decisiones en Arduino: si el botón está presionado, encendé el LED; si no, apagalo.
  • Podés sumar else para el caso contrario e incluso encadenar varias condiciones para controlar más luces.
  • · if (estado == HIGH) { digitalWrite(led, HIGH); }
  • · else { digitalWrite(led, LOW); }
  • · La condición va entre paréntesis y devuelve verdadero o falso.
  • · El bloque entre llaves se ejecuta solo si se cumple.
Hecho con dedicación · @gustavokempe

➕ Operadores aritméticos y de comparación

  • Los operadores aritméticos (+ - * / %) sirven para calcular: por ejemplo, contar cuántas veces se presionó el botón con contador = contador + 1. Los operadores de comparación (== != < > <= >=) comparan valores y devuelven verdadero o falso.
  • Cuidado con la doble igual: el operador de comparación es == (dos signos de igual), mientras que = sirve para asignar un valor.
  • · comparación: == igual, != distinto, < menor, > mayor.
  • · aritméticos: + suma, - resta, * multiplica, / divide, % resto.
  • · = asigna; == compara. Son dos operadores muy distintos.
  • · Un contador de pulsaciones usa aritmética y comparación juntas.

🙌 Actividad práctica

Control de LEDs con un botón

Armá un circuito con un pulsador y dos LEDs, y programá la lógica con if().

  1. En TinkerCad armá: un LED rojo en el pin 8, un LED verde en el pin 9 y un pulsador conectado al pin 2 con resistencia pull-down de 10 kΩ a GND.
  2. En setup(): pinMode(2, INPUT); pinMode(8, OUTPUT); pinMode(9, OUTPUT);
  3. En loop(): int estado = digitalRead(2);
  4. Agregá if (estado == HIGH) { digitalWrite(8, HIGH); digitalWrite(9, LOW); }
  5. Usá else { digitalWrite(8, LOW); digitalWrite(9, HIGH); }
  6. Probalo en la simulación: al mantener presionado se enciende el rojo, en reposo el verde.
  7. Construí el circuito real y cargá el mismo código en tu placa.
  8. Desafío: sumá un contador de pulsaciones y mostralo por el Monitor Serie.

Entrega: Captura de TinkerCad con el circuito y foto del circuito real con los dos LEDs alternando.
