La anatomía de una línea

🔤 La anatomía de una línea

Una instrucción se lee de izquierda a derecha: el nombre de la función, los paréntesis con los datos que necesita y el punto y coma que la cierra. `digitalWrite(9, HIGH);` dice qué hacer, con qué pin y con qué valor.

Las llaves abren y cierran bloques. Una función, un if o un for tienen su propio bloque. Si una llave queda sin cerrar, el compilador pierde la cuenta y marca un error muchas líneas después del problema real.

  • Nombre + paréntesis + argumentos + ;
  • Las llaves agrupan un bloque.
  • Las mayúsculas importan: pinMode no es pinmode.
  • Los comentarios // y /* */ no se ejecutan.
Una instrucción tiene nombre, paréntesis, argumentos y punto y coma. Las llaves agrupan un bloque.
Variables y tipos

📦 Variables y tipos

Una variable es un nombre que guarda un valor. El tipo dice qué clase de valor es: `int` para enteros, `float` para decimales, `char` para un carácter y `bool` para verdadero o falso. Declarar es elegir el tipo y el nombre; inicializar es darle el primer valor.

En el UNO, un `int` ocupa 2 bytes y llega hasta 32.767; un `float` ocupa 4 bytes y guarda decimales; un `char` ocupa 1 byte; un `bool`, 1 byte. Elegir mal el tipo no siempre da error: a veces da un número truncado o negativo.

  • int: enteros de −32.768 a 32.767.
  • float: decimales, 4 bytes.
  • char: un carácter, 1 byte.
  • bool: true o false, 1 byte.
Cada variable se declara con un tipo. El tipo decide qué valores acepta y cuánta memoria ocupa.
Declaración, const y alcance

🔒 Declaración, const y alcance

`const` declara un valor que no se va a modificar, como el número de pin o la velocidad del monitor. Si el programa intenta cambiarlo, el compilador avisa. Una variable común, en cambio, puede cambiar durante el programa.

El alcance define dónde existe el nombre. Una variable declarada arriba, fuera de las funciones, es global y la ven setup() y loop(). Una declarada dentro de una función es local: existe solo ahí y desaparece al terminar.

  • const: valor fijo, el compilador lo protege.
  • Variable global: fuera de las funciones.
  • Variable local: dentro de una función.
  • Una local no se ve desde otra función.
La tabla de tipos del UNO: rango, tamaño y uso típico. `const` impide que el valor cambie.
Cuando el compilador dice error

🚨 Cuando el compilador dice error

Un error de sintaxis no llega a la placa: el sketch no compila. El IDE muestra el archivo, la línea y la columna, y una descripción que casi siempre nombra el símbolo que falta. El error más común es el punto y coma; le siguen la llave sin cerrar y la mayúscula cambiada.

Se corrige el primer error y se vuelve a verificar. Un error puede tapar al siguiente: la lista de diez mensajes suele deberse a una sola línea mal cerrada.

  • Sin compilar no hay carga.
  • La consola indica archivo, línea y columna.
  • Corregir el primero y volver a verificar.
  • Punto y coma y llaves son los sospechosos.
La consola nombra el archivo, la línea y la columna. El primer error es el que hay que corregir.
