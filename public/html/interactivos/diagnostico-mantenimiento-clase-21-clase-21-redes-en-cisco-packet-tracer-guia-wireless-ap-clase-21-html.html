Guia: Modo de conexion del Access Point inalambrico

Esta guia explica como funciona el Access Point inalambrico en modo de conexion, basado en el archivo de ejemplo de Packet Tracer.

Nota: Packet Tracer es un programa en ingles. Los terminos en ingles se traducen en el glosario de abajo.

Pasos

  1. En modo de conexion Access Point inalambrico, el Access Point inalambrico se conecta al Router Principal con un cable y sirve como puente para otros dispositivos finales inalambricos y con cable.
  2. El Router Principal proporciona servicio DHCP para todos los dispositivos de la LAN, incluyendo los conectados al Access Point inalambrico.
  3. El Router Principal tambien se conecta al Router del Proveedor de Internet (ISP).
  4. Intenta acceder a la pagina web en 10.10.100.200 desde cualquiera de las PCs una vez que la red converge.
  5. NOTA: Si el Access Point inalambrico se cambia a modo Puente de Medios Inalambrico, el Enlace de Puente debe desconectarse.
