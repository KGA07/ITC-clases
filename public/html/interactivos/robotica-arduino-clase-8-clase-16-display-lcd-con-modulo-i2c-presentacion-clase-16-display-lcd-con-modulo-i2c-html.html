🖥️ El display LCD 16x2

  • El display LCD 16x2 tiene 16 columnas y 2 filas, por lo que muestra hasta 32 caracteres. Es ideal para mostrar lecturas de sensores, mensajes y estados sin depender del monitor de la PC.
  • Conectarlo directo ocuparía muchos pines; por eso usamos el módulo I2C, que lo maneja con solo dos cables de datos.
  • · 16 columnas × 2 filas = 32 caracteres.
  • · Posiciones: columna (0 a 15) y fila (0 o 1).
  • · Sirve para ver datos sin conectar la PC.
  • · Retroiluminado (backlight) para leerlo en la oscuridad.
Hecho con dedicación · @gustavokempe

🔌 El módulo I2C

  • El módulo I2C se conecta detrás del LCD y lleva la comunicación con solo dos señales: SDA (datos) y SCL (reloj), además de VCC y GND. En el Uno, SDA es A4 y SCL es A5.
  • Con I2C, el código queda elegante: creás el objeto del LCD, lo inicializás y usás funciones simples para escribir.
  • · SDA → A4 y SCL → A5 en Arduino Uno.
  • · VCC → 5V y GND → GND.
  • · Mismo bus I2C: varios módulos pueden compartirlo.
  • · El potenciómetro del módulo ajusta el contraste.

📦 Instalación manual de la librería

  • LiquidCrystal_I2C no siempre viene con el IDE: hay que instalarla. Se descarga como .zip desde GitHub oficial y se agrega en Programa → Incluir librería → Añadir librería .ZIP.
  • Una vez instalada, se importa con #include <LiquidCrystal_I2C.h> y se crea el objeto: LiquidCrystal_I2C lcd(0x27, 16, 2); (la dirección 0x27 es la típica del módulo).
  • · Descargá el .zip de LiquidCrystal_I2C desde la web oficial.
  • · IDE: Programa → Incluir librería → Añadir librería .ZIP.
  • · #include <LiquidCrystal_I2C.h> la activa en tu sketch.
  • · Dirección usual del módulo: 0x27 (a veces 0x3F).

⌨️ Funciones principales

  • Las funciones de la librería son: lcd.begin(16, 2) que inicia el display; lcd.setBacklight(HIGH/LOW) que enciende o apaga la luz; lcd.clear() que borra; lcd.setCursor(columna, fila) que posiciona el cursor; y lcd.print(texto) que escribe.
  • Un detalle clave: setCursor(0,1) coloca el cursor en la primera columna de la segunda fila. Después de escribir, podés mover el cursor y escribir otra línea.
  • · lcd.begin(16, 2): inicializa el display.
  • · lcd.setCursor(0, 0): arriba a la izquierda.
  • · lcd.print("Hola"): escribe el texto.
  • · lcd.clear(): borra todo y vuelve al inicio.

⏱️ millis(): tiempo de fondo

  • millis() devuelve los milisegundos desde que arrancó la placa, y no bloquea el programa como delay(). Con ella podés actualizar el display cada cierto tiempo mientras el resto sigue corriendo.
  • La técnica: si (millis() - ultimaActualizacion >= 2000) { actualizar display; ultimaActualizacion = millis(); } así el texto se refresca cada 2 segundos sin frenar nada.
  • · millis() cuenta desde el encendido de la placa.
  • · No detiene el programa a diferencia de delay().
  • · Compará millis() actual contra uno anterior para esperar.
  • · Ideal para refrescar texto cada ciertos segundos.

Tu nombre en el display

Mostrá un mensaje personalizado en el LCD y refrescalo usando millis().

  1. Conectá el módulo I2C: VCC a 5V, GND a GND, SDA a A4 y SCL a A5.
  2. Girá el potenciómetro del módulo hasta que el contraste se vea bien.
  3. Instalá la librería LiquidCrystal_I2C desde el .zip.
