Implementación de Servidor Web y Redes Inalámbricas

¿Terminaste rápido? Excelente. Ahora vamos a simular algo más real:
Una red Wi-Fi que accede a una página web local.

1. El Cerebro: Montar el Servidor

Necesitamos una computadora potente que guarde la página web.

  • Ve a End Devices y selecciona el icono Server (parece una torre de PC).
  • Conéctalo al Switch usando cable directo (Copper Straight-Through).
  • Configuración IP: Haz clic en el Servidor > Desktop > IP Configuration.
  • Usa la IP: 192.168.1.200 (Es común usar IPs altas para servidores).

2. Configurar el Servicio Web (HTTP)

Vamos a crear la página web que verán los usuarios.

  • En la ventana del Servidor, ve a la pestaña Services.
  • En la columna izquierda, elige HTTP.
  • Asegúrate de que donde dice "HTTP" y "HTTPS" esté marcado On.
  • En la lista de archivos, busca index.html y haz clic en (edit).
  • Borra lo que hay y escribe algo simple: <h1>Hola Mundo, Soy ****</h1>.
  • Dale a Save y confirma.

¡Ya tienes un servidor web activo!

3. Cortar los cables: Tecnología Wi-Fi

Vamos a conectar una Notebook, pero las Notebooks en Packet Tracer vienen por defecto solo con tarjeta de cable. Hay que "operarlas".

⚠️ ATENCIÓN QUIRÚRGICA:
  1. Agrega una Notebooks al área de trabajo.
  2. Haz clic en ella (Pestaña Physical).
  3. APAGA la Notebooks (botón pequeño al lado del conector amarillo). Si no la apagas, no te dejará cambiar piezas.
  4. Arrastra el módulo del puerto Ethernet (el hueco lateral) hacia la lista de módulos izquierda para quitarlo.
  5. Busca el módulo WPC300N (antena Wi-Fi) y arrástralo al hueco vacío.
  6. ENCIENDE la laptop de nuevo.

4. Conexión Inalámbrica

Para que funcione el Wi-Fi, necesitamos un Router Inalámbrico.

  • Ve a Wireless Devices y elige el WRT300N.
  • Conecta con cable el puerto Ethernet 1 del Router al Switch.
  • Espera unos segundos. La Notebook debería detectar el Router automáticamente y mostrar ondas de señal.
  • Si no conecta: Ve a la Notebooks > Desktop > PC Wireless > Connect > Refresh.

5. La Prueba de Fuego

Vamos a navegar por internet dentro de tu simulación.

  • Abre la Notebook.
  • Ve a la pestaña Desktop y busca el icono Web Browser.
  • En la barra de direcciones (URL), escribe la IP de tu servidor: 192.168.1.200
  • Presiona Go.

Si ves tu mensaje ("Hola Mundo"), ¡felicitaciones! Has creado una Intranet inalámbrica.
