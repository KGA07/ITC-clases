🦴 El esqueleto de todo programa

  • Todo programa de Arduino tiene dos funciones obligatorias: setup(), que se ejecuta una sola vez al encender la placa, y loop(), que se repite por siempre en un ciclo continuo.
  • En setup() se preparan los pines y configuraciones iniciales. En loop() se escribe la lógica que se ejecuta una y otra vez, como encender alternadamente dos LEDs o leer un sensor de forma continua.
  • · setup(): se ejecuta una sola vez al arrancar la placa.
  • · loop(): se ejecuta de forma infinita y en bucle.
  • · Todo lo que va dentro de las llaves { } forma un bloque de código.
  • · Cada instrucción termina con punto y coma (;).

✍️ El primer sketch paso a paso

  • Un sketch clásico para empezar es el que enciende y apaga el LED integrado de la placa (pin 13 del Uno). Te permite probar que todo el sistema (código + placa) funciona sin conectar ningún componente externo.
  • Escribí el código en el editor, presioná el botón Verificar para compilar y después Cargar para enviarlo a la placa. El LED de la placa debería parpadear.
Hecho con dedicación · @gustavokempe

🔌 ¿Qué pasa cuando cargás?

  • Al presionar Cargar, el IDE compila el código (lo traduce a lenguaje de máquina) y lo envía por el cable USB al microcontrolador. La placa guarda ese programa en su memoria y lo ejecuta apenas recibe energía.
  • Por eso, una vez cargado el programa, podés desconectar el USB y, si alimentás la placa con una fuente, el programa sigue funcionando solo.
  • · Compilar: traducir el código a instrucciones que entiende el chip.
  • · Cargar: transferir el programa por USB a la memoria de la placa.
  • · Luego de cargar, el programa queda guardado en la placa.
  • · Verificá siempre el modelo de placa y el puerto antes de cargar.
Hecho con dedicación · @gustavokempe

🚨 Errores comunes al empezar

  • Es normal que los primeros sketches den error. El IDE marca la línea problemática y describe el problema en la consola. Los errores más frecuentes son la falta de punto y coma, las llaves sin cerrar y escribir mal el nombre de una función.
  • · Punto y coma olvidado al final de una instrucción.
  • · Llaves { } sin abrir o cerrar correctamente.
  • · Mayúsculas: Arduino distingue tiene_tiempo de TIENE_tiempo.
  • · Leé el mensaje de la consola: suele indicar el número de línea del error.

🙌 Actividad práctica

Mi primer parpadeo

Cargá en tu placa el sketch Blink (LED integrado parpadeante) y comprobá su funcionamiento.

  1. Conectá tu Arduino por USB a la PC.
  2. Abrí el IDE y en Archivo → Ejemplos → 01.Basics abrí Blink.
  3. En Herramientas → Placa, seleccioná tu modelo (Uno o Nano).
  4. En Herramientas → Puerto, elegí el puerto donde está la placa.
  5. Presioná Verificar y esperá que compile sin errores.
  6. Presioná Cargar y observá el LED integrado (pin 13) parpadeando cada segundo.
  7. Cambiá el valor del delay de 1000 a 250, volvé a cargar y observá la diferencia.
