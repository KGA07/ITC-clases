Guía de Comandos CMD para Mantenimiento y Cuidado del Sistema (Windows 10)

Esta guía reúne los comandos más útiles del Símbolo del sistema (CMD) para mantener, limpiar y diagnosticar una PC con Windows 10. Se recomienda ejecutarlos con permisos de Administrador cuando sea necesario.

1️⃣ Comandos de mantenimiento básico

sfc /scannow

Analiza y repara archivos del sistema dañados. Ideal cuando Windows presenta errores o lentitud.

dism /online /cleanup-image /restorehealth

Repara la imagen del sistema operativo. Útil cuando el comando SFC no puede solucionar algunos problemas.

chkdsk C: /f /r

Revisa el disco duro, detecta y repara sectores defectuosos. Requiere reinicio para ejecutarse.

cleanmgr

Abre el liberador de espacio en disco para eliminar archivos temporales y basura del sistema.

defrag C: /O

Desfragmenta el disco (solo HDD). Mejora el rendimiento general del sistema.

2️⃣ Limpieza y optimización del sistema

powercfg -h off

Desactiva la hibernación, liberando varios GB de espacio en disco.

del /q /f /s *.tmp

Elimina todos los archivos temporales en las carpetas seleccionadas.

rd /s /q C:\Temp

Borra completamente la carpeta C:\Temp (y su contenido).

cipher /w:C

Elimina de forma segura los rastros de archivos eliminados en el disco.

3️⃣ Diagnóstico y monitoreo

systeminfo

Muestra información completa del sistema operativo y hardware.

wmic logicaldisk get size,freespace,caption

Muestra el espacio libre y total de cada disco.

perfmon /report

Genera un informe completo de rendimiento del sistema.

eventvwr

Abre el Visor de eventos para analizar errores del sistema y aplicaciones.

tasklist

Lista todos los procesos en ejecución.

taskkill /f /im nombre.exe

Finaliza un proceso que no responde. Ejemplo: taskkill /f /im chrome.exe

4️⃣ Comandos de red

ipconfig /all

Muestra la configuración completa de la red, IP y adaptadores.

ipconfig /flushdns

Limpia la caché DNS para resolver errores de conexión.

netsh winsock reset

Restaura la configuración de red. Soluciona problemas de conexión o Internet.

ping google.com

Verifica si hay conexión activa a Internet.

tracert google.com

Rastrea la ruta que toma la conexión hacia un servidor externo.

5️⃣ Seguridad y administración

net user

Muestra la lista de usuarios registrados en el sistema.

net user nombre /add

Crea un nuevo usuario local en el sistema.

net localgroup administrators nombre /add

Agrega un usuario al grupo de administradores.

cipher /e

Encripta una carpeta o archivo para protegerlo de accesos no autorizados.

shutdown /s /t 60

Apaga la PC con un temporizador de 60 segundos.

6️⃣ Comandos informativos

wmic cpu get name

Muestra el modelo exacto del procesador.

wmic diskdrive get model,status

Muestra el modelo y el estado del disco duro o SSD.

powercfg /batteryreport

Genera un informe de batería detallado (solo laptops). Se guarda como archivo HTML.

taskmgr

Abre el Administrador de tareas.

resmon

Abre el Monitor de recursos para analizar el uso de CPU, memoria, disco y red.

7️⃣ Secuencia recomendada de mantenimiento mensual

sfc /scannow dism /online /cleanup-image /restorehealth chkdsk C: /f cleanmgr defrag C: /O ipconfig /flushdns netsh winsock reset

Ejecuta estos comandos (en orden) una vez al mes para mantener el sistema limpio, reparado y estable.
