Las 3 Variantes de Duplicado de Alta Velocidad

1. Comando Ctrl + D: Duplica el objeto asignando una distancia de desplazamiento automático (*offset*) configurable desde la barra de propiedades libre de selección. Si mueves el primer duplicado a una posición, los siguientes recordarán el patrón exacto.

2. Tecla (+) del Teclado Numérico: Súper veloz. Saca una copia idéntica exactamente encima del objeto seleccionado, manteniendo la posición de coordenadas X e Y intacta.

3. Clic Derecho durante Arrastre: Tomas un objeto con el clic izquierdo, lo desplazas por el área de trabajo y, **antes de soltar el clic izquierdo**, presionas una vez el clic derecho del ratón. Verás aparecer un signo (+) en el cursor indicando la clonación de posición libre.
