Proyecto Áulico: Sistema POS & Automatización con IA

Guía del Alumno — Diseño de Sistemas de Información, Lógica de Fórmulas y Extensiones Cloud

1. Introducción al Proyecto

El objetivo de esta práctica es diseñar e implementar un Punto de Venta (POS) completamente funcional utilizando Google Sheets como base de datos relacional y frontend de usuario. Posteriormente, extenderemos sus capacidades nativas mediante Google Apps Script para procesar transacciones históricas, actualizar inventarios en tiempo real y conectar el sistema con modelos de Inteligencia Artificial (Generative AI) para obtener insights predictivos de negocio.

Competencias a desarrollar: Arquitectura de datos estructurados, flujos lógicos comerciales, programación orientada a eventos en JavaScript/Apps Script y consumo de APIs de IA.

2. Estructura de la Base de Datos (Las 4 Hojas)

El libro de cálculo debe estar compuesto estrictamente por 4 pestañas. A continuación se detalla la estructura formal y los tipos de datos requeridos para cada una:

Hoja 1: Inventario

Almacena los datos maestros de los productos y controla las existencias.

Columna Campo Tipo de Dato Descripción / Regla
A ID_Producto Alfanumérico Código único de barra o SKU (Clave Primaria).
B Producto Texto Nombre descriptivo del artículo.
C Categoría Texto Clasificación comercial (ej. Electrónica, Alimentos).
D Precio_Venta Moneda Precio final al consumidor.
E Stock_Actual Entero Cantidad física disponible en almacén.
F Stock_Mínimo Entero Umbral crítico para alertas de reposición.

Hoja 2: Clientes

Registro de la cartera de clientes para la personalización de la venta.

Columna Campo Tipo de Dato Descripción
A ID_Cliente Alfanumérico DNI, CUIT o código interno de cliente.
B Nombre_Completo Texto Nombre y apellido o razón social.
C Email Texto (Email) Correo electrónico para el envío del ticket digital.
D Teléfono Texto Contacto directo.

Hoja 3: Ventas

El libro diario o histórico donde se consolidarán de forma inmutable todas las transacciones procesadas.

Columna Campo Tipo de Dato Origen / Configuración
A ID_Venta Texto Generado automáticamente por el script (UUID).
B Fecha_Hora Fecha/Hora Timestamp de la transacción.
C ID_Cliente Alfanumérico Vinculado a la hoja Clientes.
D ID_Producto Alfanumérico Vinculado a la hoja Inventario.
E Cantidad Entero Unidades vendidas.
F Total_Transaccion Moneda Calculado dinámicamente (`Cantidad × Precio`).

3. Interfaz de Cobro (Hoja: Ticket) y Fórmulas Lógicas

Esta hoja actúa como la interfaz gráfica de usuario (UI) para el operador de caja. Debe diseñarse de forma limpia, separando los datos de cabecera de la grilla de productos.

Configuraciones Obligatorias:

  • Celda B3 (ID Cliente): Aplicar Validación de Datos de tipo Lista desplegable basada en el rango Clientes!A2:A.
  • Celda B4 (Nombre Cliente): Insertar la fórmula de búsqueda automatizada:
    =SI.ERROR(BUSCARV(B3; Clientes!A2:B; 2; FALSO); "Cliente No Encontrado")
  • Grilla de Artículos (Rango A8:D20):
    • Columna A (ID_Producto): Validación de datos de tipo Lista desplegable basada en Inventario!A2:A.
    • Columna B (Descripción): Búsqueda automática del nombre del producto:
      =SI(A8=""; ""; BUSCARV(A8; Inventario!A$2:B$100; 2; FALSO))
    • Columna C (Precio Unitario): Extracción automatizada del precio de venta:
      =SI(A8=""; 0; BUSCARV(A8; Inventario!A$2:D$100; 4; FALSO))
    • Columna D (Cantidad): Celda de entrada manual para el usuario.
    • Columna E (Subtotal): Multiplicación simple condicionada: =SI(A8=""; 0; C8*D8).

Nota de Diseño: Asegúrate de fijar las referencias de las matrices de búsqueda con el signo $ (ej. Inventario!A$2:D$100) para permitir el arrastre de las fórmulas sin corromper el rango de consulta.

4. Desarrollo del Backend con Google Apps Script

Los alumnos deberán ingresar al editor de código (Extensiones > Apps Script) y estructurar las funciones de negocio encargadas de persistir la venta y actualizar los inventarios de forma atómica.

/**
 * Procesa el cobro de la interfaz Ticket, guarda en Ventas y descuenta el stock.
 */
function registrarVenta() {
  const ss = SpreadsheetApp.getActiveSpreadsheet();
  const hojaTicket = ss.getSheetByName("Ticket");
  const hojaVentas = ss.getSheetByName("Ventas");
  const hojaInventario = ss.getSheetByName("Inventario");
  
  // Obtener datos de cabecera del cliente
  const idCliente = hojaTicket.getRange("B3").getValue();
  if (!idCliente) {
    SpreadsheetApp.getUi().alert("Error: Debe seleccionar un cliente antes de facturar.");
    return;
  }
  
  // Obtener la grilla de productos ingresados (Filas 8 a 20)
  const datosTicket = hojaTicket.getRange("A8:E20").getValues();
  const datetime = new Date();
  const idVenta = "TX-" + Math.floor(Math.random() * 900000 + 100000);
  
  let transaccionesAPersistir = [];
  let actualizacionesStock = {}; // Mapeo de ID_Producto -> Cantidad a restar
  
  // Procesar líneas del ticket
  for (let i = 0; i < datosTicket.length; i++) {
    let idProducto = datosTicket[i][0];
    let cantidad = datosTicket[i][3];
    let totalLinea = datosTicket[i][4];
    
    if (idProducto && cantidad > 0) {
      // Almacenar temporalmente los datos estructurales de la venta
      transaccionesAPersistir.push([idVenta, datetime, idCliente, idProducto, cantidad, totalLinea]);
      actualizacionesStock[idProducto] = cantidad;
    }
  }
  
  if (transaccionesAPersistir.length === 0) {
    SpreadsheetApp.getUi().alert("Error: El ticket no contiene artículos válidos o cantidades mayores a cero.");
    return;
  }
  
  // --- ACTUALIZAR STOCK EN INVENTARIO ---
  const datosInventario = hojaInventario.getRange("A2:E" + hojaInventario.getLastRow()).getValues();
  
  for (let i = 0; i < datosInventario.length; i++) {
    let idProdInventario = datosInventario[i][0];
    if (actualizacionesStock[idProdInventario]) {
      let stockActual = datosInventario[i][4];
      let cantidadVendida = actualizacionesStock[idProdInventario];
      
      if (stockActual < cantidadVendida) {
        SpreadsheetApp.getUi().alert("Stock insuficiente para el producto código: " + idProdInventario);
        return; // Aborta la transacción completa para resguardar la consistencia
      }
      
      // Escribir directamente la reducción en la celda correspondiente
      let filaActual = i + 2; 
      hojaInventario.getRange(filaActual, 5).setValue(stockActual - cantidadVendida);
    }
  }
  
  // --- PERSISTIR LOG DE VENTAS ---
  hojaVentas.getRowsData; // Forzar consistencia
  hojaVentas.getRange(hojaVentas.getLastRow() + 1, 1, transaccionesAPersistir.length, 6).setValues(transaccionesAPersistir);
  
  // --- LIMPIEZA DE LA INTERFAZ TICKET ---
  hojaTicket.getRange("B3").clearContent(); // Limpiar cliente
  hojaTicket.getRange("A8:A20").clearContent(); // Limpiar selectores de producto
  hojaTicket.getRange("D8:D20").clearContent(); // Limpiar cantidades
  
  SpreadsheetApp.getUi().alert("Venta registrada con éxito. Código de Operación: " + idVenta);
}

5. Integración Avanzada: Análisis de Negocio con Inteligencia Artificial

Para elevar el proyecto a un entorno moderno, conectaremos los datos históricos recopilados en la hoja de Ventas e Inventario con un modelo de lenguaje avanzado. La IA evaluará las tendencias de consumo y sugerirá decisiones de reabastecimiento o promociones específicas.

Los alumnos implementarán la siguiente función, la cual extrae el estado actual del negocio, estructura un Prompt de Ingeniería de datos y consume un endpoint seguro para desplegar un reporte estratégico:

/**
 * Extrae métricas del POS y consume un servicio de Inteligencia Artificial 
 * para generar recomendaciones automatizadas de stock y marketing.
 */
function generarInsightIA() {
  const ss = SpreadsheetApp.getActiveSpreadsheet();
  const inventario = ss.getSheetByName("Inventario").getRange("A2:F10").getValues();
  const ventas = ss.getSheetByName("Ventas").getRange("A2:F20").getValues();
  
  // Construcción del contexto del negocio textualmente para el modelo de IA
  let contextoNegocio = "Datos Actuales de Inventario (ID, Producto, Categoría, Precio, Stock, Mínimo):\n";
  inventario.forEach(row => {
    if(row[0]) contextoNegocio += `- ${row[1]} (${row[2]}): Stock:${row[4]}, Mínimo:${row[5]}\n`;
  });
  
  contextoNegocio += "\nHistórico Reciente de Ventas (ID_Venta, Cliente, ID_Producto, Cantidad, Total):\n";
  ventas.forEach(row => {
    if(row[0]) contextoNegocio += `- Factura ${row[0]}, Prod_ID: ${row[3]}, Cant: ${row[4]}, Total: $${row[5]}\n`;
  });

  const promptText = "Actúa como un Director de Operaciones y experto en Analítica de Datos. " +
                     "Basándote en los siguientes datos de mi Punto de Venta, genera un reporte ejecutivo resumido (máximo 150 palabras) " +
                     "identificando: 1) Productos en riesgo crítico de quiebre de stock, 2) El producto más rentable, y 3) Una estrategia de marketing " +
                     "para mover inventario estancado. Aquí los datos:\n" + contextoNegocio;

  // Configuración del payload para la API de Inteligencia Artificial (Ejemplo genérico estructurado)
  const apiKey = "TU_API_KEY_AQUÍ"; // Reemplazar por la clave provista en clase
  const url = "https://generativelanguage.googleapis.com/v1beta/models/gemini-1.5-flash:generateContent?key=" + apiKey;
  
  const payload = {
    "contents": [{
      "parts": [{
        "text": promptText
      }]
    }]
  };
  
  const opciones = {
    "method": "POST",
    "contentType": "application/json",
    "payload": JSON.stringify(payload),
    "muteHttpExceptions": true
  };
  
  try {
    const respuesta = UrlFetchApp.fetch(url, opciones);
    const json = JSON.parse(respuesta.getContentText());
    const insightText = json.candidates[0].content.parts[0].text;
    
    // Desplegar el reporte analítico en una caja de diálogo interactiva
    SpreadsheetApp.getUi().alert("📊 Reporte Estratégico de Inteligencia Artificial", insightText, SpreadsheetApp.getUi().ButtonSet.OK);
  } catch (error) {
    SpreadsheetApp.getUi().alert("Error de conexión con el motor de IA: " + error.toString());
  }
}

6. Guía de Ejecución Paso a Paso (Para el Alumno)

Siga rigurosamente las fases del proyecto para garantizar la correcta integración del software:

  1. Fase 1 (Modelado de Datos): Cree el libro y configure las 4 pestañas exactamente con los nombres e identificadores de columnas indicados en la Sección 2. Poblar manualmente la hoja Inventario con al menos 5 productos y la hoja Clientes con al menos 3 registros reales.
  2. Fase 2 (Desarrollo Frontend en Sheets): Maquete la pestaña Ticket cuidando la limpieza visual. Aplique las validaciones por lista desplegable y las fórmulas SI.ERROR combinadas con BUSCARV. Valide que al cambiar el ID del producto, cambie la descripción y el precio al instante.
  3. Fase 3 (Implementación Lógica): Abra el panel de Apps Script, reemplace todo el contenido vacío por las funciones de negocio provistas en esta guía. Modifique la variable de seguridad e incorpore la clave API distribuida por el docente.
  4. Fase 4 (Diseño de Componentes UX): En la hoja Ticket, inserte dos dibujos geométricos estilo botón (Insertar > Dibujo). Diseñe uno con el texto "PROCESAR COBRO" y otro con el texto "ANALIZAR CON IA". Asigne los scripts haciendo clic derecho sobre el dibujo, opción de tres puntos, e introduciendo los nombres de función exactos: registrarVenta y generarInsightIA respectivamente.
  5. Fase 5 (Prueba de Aceptación): Simule la compra de 2 unidades de un producto. Presione el botón de cobro. El sistema solicitará autorizaciones de seguridad de la cuenta de Google (otorgar accesos). Compruebe que la línea se borre del ticket, se incorpore al historial de ventas y reste el stock actual en inventario de forma matemática.
