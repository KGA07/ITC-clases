🐧 Qué es Linux y sus distribuciones

  • Linux es un sistema operativo libre cuyo núcleo (kernel) es desarrollado por miles de personas. Las 'distribuciones' (o distros) lo empaquetan con escritorio y programas: Ubuntu, Linux Mint, Debian, Fedora.
  • · Software libre: podés usarlo, estudiarlo y compartirlo sin cargo.
  • · Ubuntu: distro amigable para quienes vienen de Windows.
  • · Linux Mint: muy parecido al escritorio clásico.
  • · Existen cientos de distros para cada necesidad.
Hecho con dedicación · @gustavokempe

💿 Instalación

  • Instalar Linux es similar a Windows: se arranca desde el pendrive, se elige el teclado y la partición, y en 20-30 minutos tenés el sistema listo.
  • · Descargar la ISO de la distro elegida.
  • · Crear el pendrive booteable (Rufus o BalenaEtcher).
  • · Elegir 'Instalar Linux' (o probarlo desde la memoria primero).
  • · Seleccionar la partición o 'Borrar disco e instalar'.

🖥️ Uso básico del escritorio

  • El escritorio de Linux tiene su lógica: menú de aplicaciones, archivos, red y ajustes, con programas alternativos a los de Windows.
  • · Menú de aplicaciones: similar al Inicio de Windows.
  • · LiberOffice: la suite ofimática libre.
  • · Firefox y Chrome: los navegadores habituales.
  • · Gestor de archivos: Nautilus/Dolphin, como el Explorador.
Hecho con dedicación · @gustavokempe

🔓 Software de código abierto

  • El código abierto (open source) significa que cualquiera puede ver, modificar y distribuir el código del programa. Eso da transparencia, seguridad y actualización comunitaria.
  • · No se paga licencia por usuario.
  • · El código es legible y auditable por cualquiera.
  • · Las actualizaciones llegan del proyecto y la comunidad.
  • · Alternativas libres: LibreOffice, GIMP, VLC.
Hecho con dedicación · @gustavokempe

⚖️ Diferencias con Windows

  • Linux y Windows comparten la base lograda, pero cambian filosofía, costo, seguridad y formas de trabajo.
  • · Costo: Windows paga licencia; Linux es gratuito.
  • · Software: Windows depende de instaladores; Linux usa repositorios.
  • · Virus: Linux es menos atacado, pero no es invulnerable.
  • · Comandos: la terminal de Linux es la herramienta central para el técnico.
