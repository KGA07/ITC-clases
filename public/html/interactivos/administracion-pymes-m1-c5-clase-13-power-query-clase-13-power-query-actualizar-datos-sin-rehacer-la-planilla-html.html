Power Query: actualizar datos sin rehacer la planilla

Administración de PyMEs · ADM.
PYMES · Módulo 1 — Excel para Administración · Duración 1h 30min

Vas a conectar una planilla de gastos una sola vez y actualizarla con un clic, sin volver a copiar y pegar columnas cada mes.

Qué vas a aprender

Al terminar esta clase vas a poder:

  • Explicar qué hace Power Query y en qué se diferencia de copiar y pegar datos.
  • Conectar una tabla de Excel como origen de datos y dejarla guardada en el libro.

  • Actualizar la consulta cuando cambian los datos de origen y comprobar el resultado.
Qué es Power Query y para qué sirve en una PyME

🔄 Qué es Power Query y para qué sirve en una PyME

Power Query es el motor de importación y transformación de datos que vive dentro de Excel. Se usa cuando la información llega de afuera (una planilla de ventas, un archivo del banco, un CSV del sistema) y hay que limpiarla siempre igual.

La diferencia con copiar y pegar es que el trabajo queda guardado como una consulta: el próximo mes se actualiza y las transformaciones se repiten solas.

  • Se abre desde la ficha Datos, grupo Obtener y transformar datos.
  • Cada consulta guarda los pasos aplicados, en orden, y se pueden editar o borrar.
  • El origen no se modifica: Power Query lee y devuelve una tabla nueva en el libro.
  • Si el archivo de origen cambia de nombre o de carpeta, la consulta avisa con un error de origen.
La ficha Datos: Obtener y transformar datos, Consultas y conexiones
Traer los datos una sola vez

📥 Traer los datos una sola vez

El origen más común en una PyME es una tabla dentro del mismo libro o una planilla aparte. Desde Datos → Obtener datos se elige el tipo de archivo y se indica dónde está.

Si la información ya está en una tabla de Excel, alcanza con seleccionarla y usar Desde tabla o rango: Excel abre el editor con esa tabla como origen.

  • Datos → Obtener datos → Desde un archivo → Desde un libro de Excel.
  • Con la celda dentro de la tabla: Datos → Desde tabla o rango.
  • En el editor se elige qué columnas entran y se descartan las que no se usan.
  • Al terminar: Cerrar y cargar, y se elige tabla nueva o conexión solamente.
Obtener datos: desde archivo, desde tabla o desde otras fuentes
Transformar sin tocar el original

🧹 Transformar sin tocar el original

El editor de consultas muestra la tabla y, a la derecha, la lista de pasos aplicados. Cada acción que se hace queda como un paso con nombre: eso es lo que después se repite solo.

Las transformaciones más usadas en administración son quitar columnas, cambiar el tipo de dato (texto, número, fecha) y filtrar filas vacías o de otro período.

  • Quitar columnas: clic derecho en el encabezado → Quitar columna.
  • Cambiar tipo: clic en el ícono de tipo del encabezado (ABC, 123, calendario).
  • Filtrar: flecha del encabezado y se elige el valor o el rango.
  • Los pasos se reordenan o se borran desde la lista de la derecha; nada se aplica al archivo original.
La consulta Gastos en el panel Consultas y conexiones
Actualizar con un clic

⚡ Actualizar con un clic

Cuando llega la planilla del mes nuevo, no se rehace nada: se reemplaza el archivo de origen o se agregan filas a la tabla y se actualiza la consulta.

El resultado se puede cargar como tabla en una hoja o solo como conexión, para usarla después en una tabla dinámica.

  • Datos → Actualizar todo, o clic derecho en la consulta → Actualizar.
  • Si el origen es un archivo, conviene dejarlo siempre en la misma carpeta y con el mismo nombre.
  • Para un panel mensual: cargar como conexión y armar la tabla dinámica sobre esa consulta.
  • Revisar el mensaje de error de origen antes de rehacer la consulta: casi siempre es la ruta.

Ejercicio: Conectar la planilla de gastos

🧩 Conectar la planilla de gastos

Conectá la planilla de gastos del mes como consulta, quitá las columnas que no se usan y dejá solo fecha, proveedor, rubro e importe.

  • Abrí la planilla GastosMes.xlsx y seleccioná una celda de la tabla.
  • Datos → Desde tabla o rango.
  • En el editor, quitá las columnas Observaciones y Comprobante.
  • Cambiá el tipo de la columna Fecha a Fecha y el de Importe a Número decimal.
  • Cerrar y cargar → Solo crear conexión, y comprobá que aparece en Consultas y conexiones.
Ejercicio: Actualizar después de agregar filas

🧩 Actualizar después de agregar filas

Agregá tres gastos nuevos a la tabla de origen y actualizá la consulta sin volver a configurarla.

  • Agregá tres filas nuevas en la tabla de origen, al final.
  • Volvé a la hoja de resultados y usá Datos → Actualizar todo.
  • Comprobá que las tres filas aparecen y que las columnas quitadas siguen afuera.
  • Anotá qué pasó con el orden de los pasos.
