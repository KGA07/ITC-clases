💿 Windows 7 y su instalación

  • Windows 7 marcó una era en las oficinas y aulas. Su instalación sigue siendo la base para entender cómo se instala cualquier Windows: elegir partición, copiar archivos y configurar por primera vez.
  • · Requisitos mínimos: 1 GHz, 1-2 GB de RAM, 16-20 GB de disco.
  • · Arrancar desde pendrive o DVD con el instalador.
  • · Elegir el idioma y la edición (Home, Professional, Ultimate).
  • · En la parte de disco: seleccionar la partición destino.

🛠️ Configuración inicial del sistema

  • Después de copiar los archivos, Windows pide algunos datos: nombre de usuario, contraseña y zona horaria. Ese paso define el perfil del equipo.
  • · Nombre del equipo y nombre de usuario.
  • · Clave si se desea (en aula puede dejarse vacía).
  • · Idioma y formato de hora/teclado.
  • · Verificación de red y conexión a internet.

🔢 Arquitectura 32 y 64 bits

  • Windows 7 se consigue en versiones de 32 bits (x86) y 64 bits (x64). La principal diferencia: la cantidad de memoria RAM que puede usar el sistema.
  • · 32 bits (x86): usa hasta 4 GB de RAM y programas de 32 bits.
  • · 64 bits (x64): soporta RAM muy superior (8, 16, 32 GB...).
  • · Un programa de 64 bits no corre en un sistema de 32 bits.
  • · En equipos de hoy conviene sistemas de 64 bits.
Hecho con dedicación · @gustavokempe

💾 Archivos ISO y pendrive booteable

  • El instalador se descarga como imagen ISO (una copia exacta del disco). Para instalarlo sin lector óptico, se 'quema' esa ISO en un pendrive USB y se arranca desde él.
  • · ISO: archivo de imagen del disco de instalación.
  • · Herramientas: Rufus, Ventoy o Media Tool del mismo Windows.
  • · Seleccionar en Rufus: dispositivo, ISO y partición (MBR/GPT).
  • · En el setup, poner el pendrive primero en el boot order.

🙌 Actividad práctica

Create un pendrive booteable

Convertí un pendrive USB en un instalador de Windows 7 con la ISO provista.

  1. Conectá el pendrive y abrí Rufus.
  2. Seleccioná el dispositivo USB correcto.
  3. Cargá la imagen ISO de Windows 7.
  4. Elegí el esquema de partición según el equipo (MBR/GPT).
  5. Ejecutá la creación y verificá que el pendrive arranque.

Entrega: Pendrive booteable creado y arrancando el instalador.
