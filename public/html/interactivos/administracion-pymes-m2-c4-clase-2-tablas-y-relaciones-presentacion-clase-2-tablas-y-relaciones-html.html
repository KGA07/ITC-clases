📋 Creación de tablas y tipos de vista

  • En Access, las tablas son la columna vertebral de la base de datos: ahí se almacena toda la información. Se pueden crear desde la pestaña Crear → Tabla, y se trabajan en dos vistas principales.
  • La vista Hoja de datos permite agregar, editar y eliminar registros como en una planilla. La vista Diseño se usa para definir los campos: nombre, tipo de dato, propiedades y clave primaria.
  • · Vista Hoja de datos: pensada para cargar y consultar datos, similar a una hoja de cálculo.
  • · Vista Diseño: permite configurar la estructura de la tabla (campos, tipos, propiedades, clave primaria).
  • · Para cambiar de vista: clic derecho sobre la pestaña de la tabla → cambiar a la vista deseada.
  • · Cada campo debe tener un tipo de dato definido: Texto corto, Texto largo, Número, Moneda, Fecha/Hora, Autonumeración, Sí/No, etc.

🔧 Inserción de campos y propiedades

  • Los campos se definen en la vista Diseño. Cada campo tiene un nombre descriptivo y un tipo de dato que determina qué tipo de información puede contener. Las propiedades adicionales controlan el formato, la validación y el comportamiento.
  • · Nombre del campo: descriptivo y sin espacios (usar guión bajo si es necesario).
  • · Tipo de dato: Texto corto (hasta 255 caracteres), Número, Moneda, Fecha/Hora, Autonumeración (clave primaria automática), Sí/No.
  • · Propiedades del campo: Tamaño, Formato, Máscara de entrada, Texto de validación, Valor predeterminado, Campo requerido.
  • · La clave primaria se asigna seleccionando el campo y haciendo clic en la llave dorada de la cinta de opciones.

🔗 Relaciones entre tablas

  • Las relaciones conectan tablas para que la información no esté aislada. En una PyME, un cliente puede tener muchas facturas, y cada factura pertenece a un solo cliente. Esa conexión se establece con un campo común (clave primaria / clave foránea).
  • · Relación uno a varios: un registro de la tabla A se vincula con muchos registros de la tabla B (ej: un cliente tiene muchas facturas).
  • · Tablas intermedias (muchos a muchos): cuando dos tablas se relacionan de muchos a muchos, se crea una tabla intermedia (ej: Productos y Facturas → tabla DetalleFactura).
  • · Para crear relaciones: pestaña Herramientas de base de datos → Relaciones, arrastrar el campo clave de una tabla sobre el campo clave de la otra.
  • · Activar la integridad referencial para que Access no permita facturas sin un cliente válido.
Hecho con dedicación · @gustavokempe

📥 Importación desde Excel

  • Si ya tenés datos en una planilla Excel, no es necesario cargarlos manualmente. Access permite importar directamente desde Excel, mapeando las columnas de la hoja a los campos de la tabla.
  • · Pestaña Datos externos → Excel → Seleccionar el archivo .xlsx.
  • · Elegir si importar a una tabla nueva o agregar los datos a una tabla existente.
  • · El asistente permite mapear columnas, definir clave primaria y ajustar tipos de dato.
  • · Verificar los datos importados en la vista Hoja de datos y corregir posibles errores de formato.

🙌 Actividad práctica

Armá las tablas de stock y facturación

En la base de datos de repuestos automotores, creá las tablas Productos, Proveedores y Facturas. Establecé relaciones entre ellas e importá datos de un archivo Excel de ejemplo.

  1. Abrí la base de datos «Repuestos_Automotores.accdb» de la clase anterior.
  2. Creá la tabla Proveedores con campos: CodigoProv (Autonumeración, clave primaria), NombreProv, Telefono, Email.
  3. Modificá la tabla Productos: agregá el campo CodigoProv (Número) para vincular cada producto con su proveedor.
  4. Creá la tabla Facturas con campos: NroFactura (Número, clave primaria), FechaFactura (Fecha/Hora), CodigoCliente (Número), MontoTotal (Moneda).
  5. Abrí la ventana Relaciones (Herramientas de base de datos → Relaciones) y vinculá Productos.CodigoProv con Proveedores.CodigoProv, y Facturas.CodigoCliente con Clientes (si existe la tabla).
  6. Importá desde un archivo Excel la lista de proveedores a la tabla Proveedores usando Datos externos → Excel.

Entrega: Guardá el archivo .accdb y compartí una captura de la ventana Relaciones mostrando las conexiones entre tablas.
