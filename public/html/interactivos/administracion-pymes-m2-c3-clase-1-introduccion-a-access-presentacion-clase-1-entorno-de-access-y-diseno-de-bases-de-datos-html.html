🗄️ ¿Qué es una base de datos?

  • Una base de datos es un conjunto organizado de información almacenada en tablas con campos y registros, diseñada para ser consultada y actualizada de forma eficiente. A diferencia de una planilla Excel, donde todo puede mezclarse en una sola hoja, en Access cada dato tiene su lugar en una tabla específica.
  • En una PyME, una base de datos permite guardar clientes, proveedores, productos, facturas y movimientos de stock de manera relacionada, evitando duplicaciones y errores.
  • · Tabla: organiza la información en filas (registros) y columnas (campos).
  • · Registro: cada fila es un elemento (un cliente, un producto, una factura).
  • · Campo: cada columna describe un atributo del registro (nombre, precio, fecha).
  • · Clave primaria: campo o conjunto de campos que identifican de forma única cada registro.

✏️ Diseño de bases de datos

  • Antes de abrir Access, es fundamental diseñar la base de datos: definir qué tablas vas a crear, qué campos va a tener cada una y cómo se relacionarán entre sí. Un buen diseño ahorra horas de retoques después.
  • El proceso comienza identificando los elementos de la empresa (clientes, productos, proveedores, facturas) y luego definiendo los campos necesarios para cada uno.
  • · Listá los objetos de información: ¿qué necesita registrar la empresa? (clientes, artículos, pedidos).
  • · Definí los campos de cada tabla: nombre, tipo de dato (texto, número, fecha, moneda), longitud y si admite valores nulos.
  • · Identificá la clave primaria de cada tabla para poder relacionarlas.
  • · Evitá la redundancia: si un dato se repite en varias tablas, creá una tabla separada y vinculala con una clave foránea.

💻 El área de trabajo de Access

  • Microsoft Access presenta un entorno organizado en pestañas que facilitan la creación y gestión de todos los objetos de la base de datos: tablas, consultas, formularios e informes.
  • · Cinta de opciones: pestañas Archivo, Inicio, Crear, Datos externos, Herramientas de base de datos con grupos de comandos.
  • · Panel de navegación: lista a la izquierda todos los objetos de la base de datos agrupados por tipo.
  • · Ventana de trabajo: área central donde se editan tablas, consultas y otros objetos.
  • · Barra de estado: muestra información contextual como el modo actual (Diseño, Hoja de datos, Vista previa).

🆕 Crear una base de datos nueva

  • Para crear una nueva base de datos, se accede a Archivo → Nuevo → Base de datos en blanco. Access pide elegir la ubicación y el nombre del archivo con extensión .accdb. Luego se empieza a crear tablas desde la pestaña Crear.
  • · En Archivo → Nuevo, seleccioná «Base de datos en blanco» y guardá el archivo con un nombre descriptivo (ej: PyME_Taller.accdb).
  • · La primera tabla aparece en modo Hoja de datos: ahí se definen los campos haciendo clic en «Haga clic para agregar».
  • · Para definir tipos de dato y propiedades, cambiá a la vista Diseño con clic derecho sobre la pestaña de la tabla.
  • · Guardá constantemente con Ctrl + S para no perder avances.

🙌 Actividad práctica

Creá tu primera base de datos de una PyME

Creá en Access una base de datos para una empresa de repuestos automotores que necesita organizar sus clientes y productos. Definí la estructura antes de abrir Access.

  1. En papel o en un documento, listá los campos necesarios para una tabla de Clientes (nombre, teléfono, email, dirección) y otra de Productos (código, descripción, precio, stock).
  2. Abrí Microsoft Access y creá una nueva base de datos en blanco llamada «Repuestos_Automotores.accdb».
  3. En la primera tabla, definí los campos de Clientes en vista Diseño: asigná tipo Texto a nombre, teléfono, email y dirección; elegí un campo como clave primaria.
  4. Creá una segunda tabla para Productos: campo Código (Número corto, clave primaria), Descripción (Texto), Precio (Moneda), Stock (Número entero).
  5. Guardá ambas tablas y verificá que aparezcan en el Panel de navegación.

Entrega: Guardá el archivo .accdb y compartí una captura del Panel de navegación mostrando ambas tablas.
