✒️ Las reglas de escritura

  • La sintaxis es el conjunto de reglas para escribir código que la placa entienda. En Arduino, cada instrucción termina con punto y coma, los bloques van entre llaves { } y los comentarios se escriben con // para una línea o /* */ para varias.
  • Una buena práctica: escribir comentarios que expliquen qué hace cada parte. Cuando vuelvas a leer el código a la semana, te vas a agradecer a vos mismo.
  • · // comentario de una línea.
  • · /* ... */ comentario de varias líneas.
  • · Cada instrucción (statement) termina en ;
  • · Las llaves { } agrupan bloques como setup() y loop().

📦 Variables y constantes

  • Una variable es un espacio de memoria con nombre donde guardás un valor que puede cambiar. Una constante es un valor que no cambia durante el programa, y se declara con const.
  • Declarar e inicializar es definir el tipo y el nombre, y asignarle un primer valor. Podés hacerlo en la misma línea: int contador = 0; o hacerlo después: int contador; contador = 0;
  • · Declaración: indicar tipo y nombre, por ejemplo int led;
  • · Inicialización: darle el primer valor, por ejemplo led = 13;
  • · En una línea: int led = 13;
  • · Constante: const int pinBoton = 2; (no se puede reasignar).

🔤 Tipos de datos

  • Arduino maneja varios tipos de datos según el valor que quieras guardar. Elegir el tipo correcto ahorra memoria y evita resultados inesperados.
  • Los tipos principales son int (números enteros), float (números con coma, como temperaturas), char (un solo carácter) y boolean (verdadero o falso). También existe String para cadenas de texto, que veremos más adelante con el Serial.
  • · int: números enteros, por ejemplo la hora en segundos.
  • · float: números decimales, por ejemplo 23.5 °C.
  • · char: una letra, por ejemplo 'A'.
  • · bool: true o false, por ejemplo la lectura de un pulsador.
  • · long: números enteros grandes, por ejemplo millis() largo.

🌐 Ámbito de las variables

  • El ámbito indica desde qué partes del código se puede usar una variable. Las variables globales se declaran fuera de las funciones, al inicio del sketch, y son visibles en todo el programa. Las locales se declaran dentro de una función y solo existen ahí.
  • Es una convención común declarar las constantes de pines como globales arriba del código: así cualquier función puede usarlas y son fáciles de cambiar en un solo lugar.
  • · Global: declarada fuera de toda función, visible en todo el sketch.
  • · Local: declarada dentro de setup(), loop() u otra función, solo se usa ahí.
  • · Una variable local no se puede leer fuera de su función.
  • · Declarar las constantes de pines arriba hace el código más ordenado.

🙌 Actividad práctica

Mi primer código bien declarado

Escribí un sketch que declare constantes y variables con buen estilo, y probalo en la placa.

  1. Declará arriba del setup(): const int pinLed = 13;
  2. Declará también: int duracion = 1000;
  3. En setup(), ejecutá pinMode(pinLed, OUTPUT);
  4. En loop(), prende el LED con digitalWrite(pinLed, HIGH); delay(duracion); (probad que compila).
  5. Cambiá el valor de duracion a 250 y volvé a cargar: el parpadeo cambia sin modificar loop().
  6. Probá declarar una variable local dentro de loop() llamada retardo = 100; y usala con delay(retardo);
  7. Cargá el código final y corroborá que parpadea usando ambas variables.

Entrega: Captura del sketch final con const int, int global y variable local bien comentada.
