🖥️ El Escritorio y el Menú Inicio

  • El Escritorio es la pantalla principal de Windows: ahí viven los íconos, accesos directos y la barra de tareas. El Menú Inicio está en la esquina inferior izquierda y es el punto de entrada a todos los programas.
  • · Windows 10: los íconos del Menú Inicio aparecen como cuadros organizados (Live Tiles).
  • · Windows 11: menú y barra centrados, con bordes redondeados y apariencia más limpia.
  • · Consejo profesional: presioná la tecla Windows y escribí el nombre del programa para encontrarlo al instante.
Hecho con dedicación · @gustavokempe

📁 El Explorador de archivos

  • El Explorador de archivos es la herramienta para ver y organizar todos los archivos y carpetas del equipo.
  • · Barra de navegación: panel izquierdo con Escritorio, Documentos, Descargas y unidades.
  • · Cinta de opciones: herramientas para copiar, mover, eliminar y organizar.
  • · Área de contenido: la zona donde ves tus archivos y carpetas.
  • · Vistas: 'Iconos grandes' para fotos, 'Detalles' para ver fechas, tamaños y tipos.
Hecho con dedicación · @gustavokempe

✂️ Crear, copiar, mover y borrar

  • Saber mover documentación sin equivocarse es una tarea diaria del asistente administrativo. Los atajos de teclado son la forma más rápida y segura de hacerlo.
  • · Ctrl + C: copiar el elemento seleccionado sin eliminarlo del original.
  • · Ctrl + X: cortar para mover (el elemento queda 'sobre el portapapeles').
  • · Ctrl + V: pegar donde esté el cursor o la carpeta abierta.
  • · Ctrl + Z: deshacer la última acción. ¡Tu salvavidas digital!
  • · Para borrar: seleccionar con clic y presionar Supr, confirmando que no vas a necesitarlo.
Hecho con dedicación · @gustavokempe

💾 ¿Dónde guardo mis cosas?

  • Conocer las opciones de almacenamiento y sus ventajas te ayuda a decidir dónde guardar cada archivo.
  • · Disco Local (C:): el corazón de tu PC, acceso rápido y constante sin internet. Si la PC falla, recuperar datos puede ser difícil.
  • · Pendrive (USB): portátil y práctico, sin internet. Cuidado: puede perderse o dañarse físicamente.
  • · Nube (Drive/OneDrive): acceso desde cualquier lugar con internet y copias de seguridad automáticas. Protegido aunque el equipo se dañe.

🙌 Actividad práctica

Organizá tu archivo digital

Creá una estructura de carpetas lógica y profesional para separar tus documentos personales de los de trabajo, aplicando lo visto en clase.

  1. Creá tu carpeta personal con tu nombre: clic derecho → Nuevo → Carpeta.
  2. Dentro, creá tres carpetas temáticas: «Facturas», «Recibos» y «Documentos de trabajo».
  3. Copiá un archivo existente (Ctrl + C / Ctrl + V) y movelo a la carpeta correcta (Ctrl + X / Ctrl + V).
  4. Borrá un archivo que no uses (Supr) y confirmá la acción.
  5. Verificá el resultado en el Explorador de archivos: vista Detalles para ver fechas y tamaños.

Entrega: Capturá la pantalla (Win + Shift + S) mostrando tu estructura de carpetas y el archivo movido.
