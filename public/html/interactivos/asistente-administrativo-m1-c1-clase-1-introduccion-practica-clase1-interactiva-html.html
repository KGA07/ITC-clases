Organización del Escritorio

Práctica interactiva para aprender a organizar tus archivos

Introducción

Organizar tu escritorio digital es clave para trabajar de manera eficiente. En esta práctica, aprenderás a:

  • Crear carpetas principales para diferentes tipos de archivos.
  • Organizar subcarpetas para mantener todo ordenado.
  • Guardar archivos de manera sistemática.

Sigue los pasos a continuación y luego aplica lo aprendido en tu propio ejercicio.

Pasos Prácticos

1. Abrir el escritorio y crear una carpeta

En tu escritorio, haz clic derecho y selecciona "Nueva carpeta". Dale un nombre descriptivo como "Trabajo" o "Documentos".

2. Crear subcarpetas para documentos

Dentro de la carpeta principal, crea subcarpetas como "Proyectos", "Facturas" o "Notas". Esto te ayudará a mantener todo organizado.

3. Guardar un archivo de prueba

Crea un archivo de texto (puede ser un documento Word o PDF) y guárdalo dentro de la subcarpeta "Proyectos". Nómbralo con una descripción clara, como "Proyecto_X_Descripción".

Ejercicio Interactivo

Describe el proceso que seguirías para organizar los archivos de un nuevo proyecto en tu escritorio. Incluye:

  • Nombre de la carpeta principal.
  • Subcarpetas que crearías.
  • Ejemplo de cómo nombrarías un archivo.
