1. ¿Qué función principal cumple la placa madre (motherboard) en una PC? Placa madre
  • Es el dispositivo que almacena el sistema operativo.
  • Conecta y permite la comunicación entre todos los componentes del PC.
  • Solo se encarga de la energía eléctrica de los componentes.

La placa madre es la base donde se conectan y se comunican microprocesador, RAM, almacenamiento y otros dispositivos.

2. ¿Qué es el socket de la placa madre? Placa madre
  • El conector para los discos duros y SSD.
  • El conector donde se enchufa la fuente de alimentación.
  • El zócalo específico donde se instala el microprocesador.

El socket es el zócalo físico diseñado para un tipo de microprocesador específico (por modelo y generación).

3. ¿Cuál es la mejor descripción del microprocesador (CPU)? Microprocesador
  • Es el “cerebro” del equipo, ejecuta instrucciones y realiza cálculos.
  • Es el dispositivo que almacena los archivos de forma permanente.
  • Es el encargado de convertir la corriente alterna en continua.

La CPU interpreta y ejecuta instrucciones de los programas y del sistema operativo.

4. ¿Qué característica principal tiene la memoria RAM? Memoria RAM
  • Almacena datos de forma permanente aunque se apague el PC.
  • Es una memoria volátil: su contenido se pierde al apagar el equipo.
  • Solo se utiliza para guardar documentos de usuario.

La memoria RAM almacena datos e instrucciones de uso inmediato. Es rápida pero pierde su contenido al apagar el sistema.

5. ¿Qué efecto suele tener aumentar la cantidad de memoria RAM? Memoria RAM
  • Hace que el disco duro gire más rápido.
  • Solo mejora la calidad de imagen en el monitor.
  • Permite abrir más programas al mismo tiempo con mayor fluidez.

Más RAM permite manejar más aplicaciones y datos en memoria sin depender tanto del disco como memoria virtual.

6. ¿Cuál de las siguientes opciones es una unidad de almacenamiento de estado sólido? Almacenamiento
  • SSD (Solid State Drive).
  • HDD de 3,5" mecánico.
  • Unidad lectora de DVD.

Los SSD no tienen partes móviles, son más rápidos y resistentes a golpes que los discos mecánicos tradicionales.

7. ¿Qué hace la fuente de alimentación en una computadora? Fuente de alimentación
  • Almacena los archivos de usuario y del sistema.
  • Convierte la corriente alterna en corriente continua y distribuye energía a los componentes.
  • Controla la velocidad de la red de Internet.

La fuente convierte la energía de la red eléctrica a tensiones seguras para placa madre, CPU, discos, etc.

8. ¿Por qué es importante elegir una fuente de alimentación de buena calidad? Fuente de alimentación
  • Porque una fuente de mala calidad puede provocar fallas, reinicios y dañar otros componentes.
  • Solo influye en el color de la pantalla.
  • No es importante, todas las fuentes funcionan igual.

Una fuente inestable puede generar picos de tensión, cortes y, en casos extremos, dañar hardware.

9. ¿Qué es un sistema operativo como Windows? Windows
  • Un programa opcional solo para jugar.
  • Un componente físico que se conecta a la placa madre.
  • El software que administra el hardware y permite que el usuario use la computadora.

El sistema operativo gestiona recursos (CPU, memoria, dispositivos) y ofrece la interfaz para trabajar con el PC.

10. ¿Cuál de estas acciones ayuda al buen funcionamiento de Windows? Windows
  • Instalar programas desde cualquier sitio desconocido.
  • Mantener el sistema actualizado y usar un antivirus confiable.
  • Desactivar todas las actualizaciones y nunca reiniciar el equipo.

Actualizar Windows y usar antivirus reduce vulnerabilidades y mejora estabilidad y seguridad.
