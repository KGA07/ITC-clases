Ingreso de datos por Serial

Robótica con Arduino · ROBÓTICA
ARDUINO · Módulo 2 — Electricidad, código y salidas · Duración 1h 30min

Hasta ahora la placa hablaba y la computadora escuchaba. En esta clase se invierte: se escriben números en el monitor y la placa los usa para prender, apagar o cambiar el brillo de un LED.

Qué vas a aprender

Al terminar esta clase vas a poder:

  • Enviar números desde el monitor serie y leerlos con parseInt().
  • Explicar available(), read() y parseInt().
  • Controlar un LED con comandos (0, 1, 2 y 0-255).
  • Explicar por qué read() devuelve ASCII y parseInt() devuelve un número.
El IDE y el monitor

🖥️ El IDE y el monitor

El monitor serie tiene una caja de texto y un botón Enviar. Lo que se escribe ahí viaja por el USB a la placa, carácter por carácter. El sketch lo lee y lo interpreta.

La placa no sabe qué es un número hasta que lo convierte. Primero llegan caracteres; después, una función los agrupa y los transforma en un entero.

  • El monitor también envía.
  • Se escribe el número y se presiona Enviar.
  • La placa recibe caracteres, no números.
  • La conversión la hace el sketch.
El sketch recibe un número y decide qué hacer. El monitor es la entrada, no solo la salida.
Enviar comandos

⌨️ Enviar comandos

En esta clase hay cuatro comandos: 0 apaga el LED, 1 lo enciende, 2 lo hace parpadear tres veces y un número entre 3 y 255 fija el brillo con PWM. Cualquier otro valor devuelve un mensaje de error.

El monitor envía texto: «255» son tres caracteres, no un byte. El sketch tiene que leerlos todos antes de convertirlos. Por eso se usa parseInt() y no read().

  • 0: apagado; 1: encendido.
  • 2: parpadeo; 3-255: brillo.
  • Otro valor: error.
  • «255» son tres caracteres.
Un comando por línea: 0 apaga, 1 enciende, 2 parpadea y 3-255 fija el brillo.
available, read y parseInt

🔢 available, read y parseInt

Serial.available() devuelve cuántos caracteres hay en el buffer. Si devuelve 0, no hay nada y el bloque no se ejecuta. Es la forma de no quedarse esperando.

Serial.read() saca un carácter y devuelve su código ASCII: el carácter '2' devuelve 50, no 2. Serial.parseInt() lee los dígitos y devuelve el número: '255' devuelve 255. Para un comando numérico, parseInt() es el atajo.

  • available(): cuántos caracteres hay.
  • read(): un carácter, código ASCII.
  • parseInt(): el número completo.
  • Sin available(), el loop no espera.
available() dice si hay algo; read() saca un carácter; parseInt() arma el número completo.
Comandos y límites

📋 Comandos y límites

El comando se interpreta con if/else. Si el número es 0, se apaga; si es 1, se enciende; si es 2, se parpadea; si está entre 3 y 255, se usa analogWrite. Cualquier otro valor cae en el mensaje de error.

El brillo solo funciona en un pin PWM. Si el LED está en un pin que no es PWM, los comandos 0, 1 y 2 funcionan, pero el brillo no modula: el LED queda encendido o apagado.

  • if/else para cada comando.
  • 3-255 usa analogWrite.
  • El pin tiene que ser PWM.
  • Otro valor: mensaje de error.
Cada comando tiene una acción. El sketch decide qué hacer con el número que llega.
