Recuperación del sistema

¿PC que no arranca, archivos perdidos o cuentas bloqueadas? Hoy aprendés a recuperar equipos: Linux Live para acceder al disco, la consola de recuperación de Windows y el restablecimiento de contraseñas.

✈️ Linux Live para rescatar equipos

  • Un Linux Live es el sistema 'de rescate': arranca desde el pendrive sin tocar el disco. Desde ahí podés ver todas las particiones aunque Windows no inicie y copiar archivos a otro dispositivo.
  • · Arranca sin instalar nada y ajeno al disco interno.
  • · Ve particiones NTFS y ext4 sin problemas.
  • · Ideal para respaldar archivos de un equipo 'muerto'.
  • · Antes de cualquier reparación: copiar todo lo importante.
Hecho con dedicación · @gustavokempe

🖥️ CMD en el arranque de Windows

  • Windows ofrece un entorno de recuperación (WinRE) que se abre al fallar el arranque o con una tecla especial. Desde ahí, 'Símbolo del sistema' muestra un CMD con herramientas de reparación.
  • · Acceso: opciones de recuperación de Windows.
  • · Comandos útiles: bootrec /fixmbr, /fixboot, /rebuildbcd.
  • · sfc /scannow verifica archivos del sistema.
  • · El CMD solo permite reparar, no reemplaza al sistema arrancado.
Hecho con dedicación · @gustavokempe

🗂️ Acceso al disco y recuperación de archivos

  • Con el disco montado desde Linux Live o con programas de recuperación, podés rescatar fotos y documentos aunque Windows no quiera abrir.
  • · Montar la partición en Linux Live y navegar los archivos.
  • · Copiar a un pendrive o disco externo sano.
  • · Programas de recuperación para archivos borrados: recuva, testdisk, photorec.
  • · No instalar software en el disco dañado.
Hecho con dedicación · @gustavokempe

🔑 Restablecimiento de contraseña de Windows

  • Cuando el usuario olvida su contraseña, el técnico puede restablecerla sin perder los archivos, con herramientas de recuperación o desde el CMD.
  • · En Windows 10/11 hay opciones de restablecimiento integradas.
  • · Herramientas como Offline NT Password lo hacen desde un Live.
  • · Nunca se 'descifra': se reemplaza la contraseña.
  • · Después del restablecimiento, avisar al usuario de cambiar la clave.
Hecho con dedicación · @gustavokempe

✅ Secuencia de rescate paso a paso

  • La metodología del técnico: primero el respaldo, después la reparación. Nunca se trabaja sobre un disco sin haber rescatado lo valioso.
  • · 1. Arrancar con Linux Live.
  • · 2. Montar el disco y respaldar archivos críticos.
  • · 3. Reparar el arranque o el sistema.
  • · 4. Restablecer contraseñas y devolver la PC.
