Finalización y exportación de datos

Vas a cerrar la base de datos como un producto terminado: con un menú de inicio que guía al usuario y con exportación de tablas, consultas e informes a PDF.

⏱ 1h 30min 🎓 Presencial con PC individual Año 2026

🏠 El menú de inicio

  • Un formulario de menú (menú principal) es la puerta de entrada a la base. Su diseño es simple: un formulario en blanco con el título de la empresa y botones que ejecutan acciones como abrir formularios, consultas o informes.
  • Para que la base arranque directamente en el menú, se indica en las Opciones de inicio cuál es el formulario que se abre primero.
  • · Formulario en blanco: pestaña Crear → Formulario en blanco.
  • · Los botones se colocan con el control Botón de la pestaña Diseño.
  • · Cada botón ejecuta una acción: abrir formulario, abrir consulta, abrir informe, o una macro.
  • · Las acciones de los botones se definen con el Asistente para botones de comandos o con macros.
Hecho con dedicación · @gustavokempe

🔘 Botones de menú y macros de arranque

  • El Asistente para botones de comandos ofrece categorías de acciones listas para usar: abrir un formulario, abrir un informe, terminar la aplicación. Al soltar el botón, el asistente pregunta qué categoría y qué comando asignar, y si se quiere adjuntar una macro para ejecutar después.
  • · Categoría «Operaciones con formularios» → «Abrir formulario»: elegí el formulario objetivo.
  • · Categoría «Operaciones con informes» → «Vista previa informe»: abrir la vista previa del informe.
  • · Categoría «Aplicación» → «Terminar la aplicación»: botón de salida de Access.
  • · Los botones se agrupan en el menú con rótulos claros: Clientes, Productos, Facturas, Informes, Salir.

⚙️ Propiedades de la base de datos

  • Las propiedades generales identifican la base de datos: título, autor, empresa y comentarios. También se configuran las opciones de inicio para controlar cómo se muestra la base al abrirse: qué formulario es el inicial, si se muestra el panel de navegación, etc.
  • · Información general: Archivo → Información → Ver y editar propiedades de la base.
  • · Título de la aplicación y autor en los cuadros de «Propiedades del documento».
  • · Opciones de inicio: Archivo → Opciones → Base de datos actual: campo «Formulario de aplicación». IA Función.
  • · Configurar el formulario de inicio permite que la base abra directamente en el menú.

📄 Exportación a PDF

  • Exportar a PDF es la forma estándar de compartir informes, listados y documentación sin que nadie modifique los datos. Se exportan tablas, consultas y especialmente informes desde la pestaña Datos externos.
  • · Seleccionar el objeto (consulta o informe) → pestaña Datos externos → PDF o XPS.
  • · Elegir la ubicación, el nombre del archivo y las opciones de diseño (páginas, calidad).
  • · Un informe exportado a PDF mantiene el formato exacto y se puede enviar por mail o imprimir.
  • · En el caso de tablas y consultas, PDF es una vista para lectura; para entregar datos editables conviene Excel.

🙌 Actividad práctica

Terminá tu base con menú y exportaciones

Armá el menú de inicio de la base de datos de repuestos, configurá las propiedades y exportá a PDF el listado de productos y un informe.

  1. Creá un formulario en blanco (Crear → Formulario en blanco) y agregá en el encabezado el título «Repuestos Automotores – Sistema de Gestión».
  2. Con el control Botón, agregá en el menú los botones: Clientes (abre FormClientes), Productos (abre la tabla o formulario de productos), Facturas (abre el formulario de facturas) y Remitos (abre la vista previa del informe RemitoVenta).
  3. Agregá un botón de salida con la categoría «Aplicación → Terminar la aplicación».
  4. Guardá el formulario como «MenuPrincipal».
  5. En Archivo → Opciones → Base de datos actual, configurá el Formulario de aplicación como MenuPrincipal para que la base abra ahí.
  6. Cerrá y volvé a abrir la base para verificar que arranca en el menú.
  7. En la pestaña Datos externos, exportá el informe de listado de productos y el remito de venta a PDF.

Entrega: Guardá el archivo .accdb final y entregá los dos PDF exportados: el listado de productos y el remito de venta.
