🌐 TCP/IP: dirección IP v4 y v6

  • Cada equipo en una red necesita una dirección para ser encontrado: la IP. La v4 (192.168.1.x) es la clásica y la v6 la versión moderna con direcciones enormes.
  • · IP v4: cuatro números separados por puntos (192.168.0.10).
  • · IP v6: ocho bloques hexagonales (fe80::...).
  • · La IP identifica cada equipo dentro de la red.
  • · Hoy conviven ambas versiones en los equipos modernos.
Hecho con dedicación · @gustavokempe

🧭 Máscara, puerta de enlace y DNS

  • Una IP sola no alcanza: la máscara define la porción de red, la puerta de enlace (gateway) sale hacia afuera y el DNS traduce nombres de dominio a IPs.
  • · Máscara: separa red y equipo (255.255.255.0 es lo típico).
  • · Puerta de enlace: IP del router para salir a internet.
  • · DNS: traduce www.ejemplo.com a su dirección IP real.
  • · Estos 4 datos forman la configuración IP de un equipo.
Hecho con dedicación · @gustavokempe

🤝 Servidor DHCP

  • Para no escribir datos a mano, el router actúa como servidor DHCP: entrega IP, máscara, puerta de enlace y DNS automáticamente a cada equipo que se conecta.
  • · DHCP: protocolo de configuración dinámica de equipos.
  • · El router reparte direcciones de un rango (pool).
  • · El equipo pide y el servidor asigna en segundos.
  • · Configuración manual (estática) se usa para impresoras y servidores.
Hecho con dedicación · @gustavokempe

🖥️ Configuración de red en el equipo

  • En el equipo se configura el nombre, el grupo de trabajo y el protocolo TCP/IP, y se prueban las conexiones con ping. Compartir carpetas e impresoras permite que todos usen lo mismo.
  • · Nombre del equipo y grupo de trabajo (WORKGROUP).
  • · Protocolo TCP/IP v4: automático (DHCP) o manual.
  • · Ping: prueba de conectividad (ping 192.168.0.1).
  • · Compartir carpetas e impresoras y mapear unidades de red.
Hecho con dedicación · @gustavokempe

📶 Router: configuración básica y avanzada

  • El router se configura desde su panel web: estado WAN/LAN/WLAN, red WiFi con SSID y cifrado, y opciones avanzadas como WPS, filtrado MAC y puertos.
  • · WAN: la conexión hacia internet (PPPoE, IP dinámica).
  • · LAN: la red local, su IP, DHCP y máscara.
  • · WLAN: WiFi: SSID, canal y cifrado (WPA2/WPA3).
  • · Avanzado: filtrado MAC, reserva de IP, puertos y control de acceso.
Hecho con dedicación · @gustavokempe

🧪 Simulá la red en Packet Tracer antes de armarla

  • Antes de tocar el router real, la red completa se puede armar en Packet Tracer: router, switch, puntos de acceso y PCs arrastrados al lienzo, conectados con cables o WiFi y probados con ping y páginas web.
  • · Se arma la topología real: router, AP y equipos en el lienzo.
  • · El router simulado entrega DHCP a todos los equipos, igual que el real.
  • · Se accede a páginas web del servidor simulado para probar la red.
  • · Los comandos y paneles mostrados son los mismos que usa el router de verdad.
