Clase 2: Estructurando el corazón de nuestra Base de Datos

Objetivos del Negocio y la BD

Dinámica del Negocio

Toda Pyme, como una tienda de ropa, funciona con dos pilares:

  • Venta: Comercialización de productos a Clientes.
  • Compra: Adquisición de stock a Proveedores.

Objetivos de la Base de Datos

Para administrar esto, nuestra BD debe:

  • Registrar Ventas (precios, cantidades).
  • Registrar Compras (costos).
  • Controlar el Stock disponible.
  • Calcular precios, ganancias e IVA.

Estructura Base: Tienda de Ropa

Para cumplir los objetivos, dividiremos la información en 3 Tablas principales.

Tabla 1: PRENDAS

Almacena todo el catálogo: descripciones, talles, colores, precios y stock.

Tabla 2: PROVEEDORES

Guarda los datos de contacto, Razón Social y CUIT de quienes nos abastecen.

Tabla 3: CLIENTES

Registra la información de las personas que compran nuestros artículos.

Asistente p/Búsqueda

Permite crear una lista de valores fija (ej: S, M, L, XL para Talles) evitando errores de tipeo.

Moneda vs Número

Usamos Moneda para importes que llevan símbolo $, y Número para cantidades (Stock).

La Clave Principal

Es el campo que identifica de forma única e irrepetible a cada registro dentro de su tabla.


  • En Proveedores: Id-PROV
  • En Prendas: Id-ART
  • Evita que existan dos artículos o proveedores con el mismo código.
