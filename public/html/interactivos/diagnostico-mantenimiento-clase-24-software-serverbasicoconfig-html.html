Servidores en Packet Tracer

Introducción Topología Configuración Servicios Simulación

Guía para Simular Servidores Básicos

Bienvenido a esta guía interactiva para aprender a construir y simular una red simple con servicios de servidor básicos utilizando Cisco Packet Tracer v8.2.2. Este tutorial está diseñado para ser seguido paso a paso, desde la creación de la topología física hasta la verificación del funcionamiento de servicios como HTTP, DHCP y DNS. El objetivo es proporcionar una base sólida y práctica para entender cómo funcionan los servidores en un entorno de red controlado.

Paso 1: Creación de la Topología

El primer paso es construir la estructura física de nuestra red. Añadiremos un servidor, un PC cliente y un switch para interconectarlos. Utilizaremos cables de cobre de par trenzado directo (Copper Straight-Through) para las conexiones, que es el estándar para conectar dispositivos finales a un switch.

Diagrama de la Red

💻 PC-Cliente
🔄 Switch 2960
🗄️ Servidor

Instrucciones:

  1. Desde la barra de dispositivos, selecciona End Devices y arrastra un PC y un Server al área de trabajo.
  2. Selecciona Switches y arrastra un switch modelo 2960.
  3. Selecciona Connections, elige el cable Copper Straight-Through (línea negra continua).
  4. Conecta el PC (puerto FastEthernet0) al Switch (puerto FastEthernet0/1).
  5. Conecta el Servidor (puerto FastEthernet0) al Switch (puerto FastEthernet0/2).

Paso 2: Configuración de Direcciones IP

Para que los dispositivos puedan comunicarse, necesitan una dirección única en la red. Configuraremos direcciones IP estáticas. El servidor tendrá una IP fija para que los clientes siempre sepan cómo encontrarlo, y al PC le asignaremos una IP manualmente para la prueba inicial.

Configuración del Servidor

Haz clic en el Servidor, ve a la pestaña Desktop > IP Configuration.

  • IP Address: 192.168.1.1
  • Subnet Mask: 255.255.255.0
  • Default Gateway: 192.168.1.1 (apunta a sí mismo)
  • DNS Server: 192.168.1.1 (será su propio servidor DNS)

Configuración del PC-Cliente (Estática)

Haz clic en el PC, ve a la pestaña Desktop > IP Configuration.

  • IP Address: 192.168.1.10
  • Subnet Mask: 255.255.255.0
  • Default Gateway: 192.168.1.1
  • DNS Server: 192.168.1.1

Paso 3: Configuración de Servicios del Servidor

Aquí es donde convertimos nuestro dispositivo "Servidor" en un servidor funcional. Habilitaremos y configuraremos los servicios HTTP (para alojar una página web), DHCP (para asignar IPs automáticamente) y DNS (para traducir nombres de dominio a IPs). Selecciona un servicio para ver las instrucciones.

Servicio HTTP (Servidor Web)

  1. Haz clic en el Servidor y ve a la pestaña Services.
  2. En el menú de la izquierda, selecciona HTTP.
  3. Asegúrate de que tanto HTTP como HTTPS estén en la posición On.
  4. (Opcional) Puedes hacer clic en index.html y luego en Edit para personalizar la página de bienvenida.

Servicio DHCP (Asignación Automática de IP)

  1. En la misma pestaña Services del Servidor, selecciona DHCP.
  2. Enciende el servicio (On).
  3. Configura el "pool" de direcciones:
    • Default Gateway: 192.168.1.1
    • DNS Server: 192.168.1.1
    • Start IP Address: 192.168.1.100 (para empezar a asignar desde aquí).
    • Subnet Mask: 255.255.255.0
    • Maximum Number of Users: 50
  4. Haz clic en Save para guardar la configuración del pool.

Servicio DNS (Sistema de Nombres de Dominio)

  1. En la pestaña Services del Servidor, selecciona DNS.
  2. Enciende el servicio (On).
  3. Crea un registro para tu servidor web:
    • Name: www.miservidor.com
    • Type: A Record
    • Address: 192.168.1.1
  4. Haz clic en Add para añadir el registro a la tabla.

Paso 4: Simulación y Verificación

Es hora de probar si todo funciona como se esperaba. Realizaremos pruebas desde el PC-Cliente para verificar la conectividad básica y el correcto funcionamiento de cada uno de los servicios que hemos configurado en el servidor. Selecciona una prueba para ver las instrucciones.

Prueba de Conectividad con Ping

  1. Haz clic en el PC-Cliente, ve a la pestaña Desktop y abre Command Prompt.
  2. Escribe el comando: ping 192.168.1.1
  3. Presiona Enter. Deberías recibir 4 respuestas (Reply from 192.168.1.1...), lo que indica que hay conectividad.

Prueba del Servidor Web

  1. En el PC-Cliente, abre el Web Browser desde la pestaña Desktop.
  2. En la barra de URL, escribe la dirección IP del servidor: 192.168.1.1 y presiona Go.
  3. Debería aparecer la página de bienvenida de Cisco Packet Tracer, confirmando que el servicio HTTP funciona.

Prueba del Servicio DHCP

  1. Vuelve a la configuración de IP del PC-Cliente (Desktop > IP Configuration).
  2. Selecciona la opción DHCP en lugar de Static.
  3. Espera unos segundos. El PC debería recibir automáticamente una dirección IP del rango que configuraste (ej. 192.168.1.100), junto con la máscara, gateway y DNS. Esto confirma que DHCP funciona.

Prueba de Resolución DNS

  1. Asegúrate de que el PC tenga la IP del DNS configurada (ya sea estáticamente o vía DHCP).
  2. Abre nuevamente el Web Browser en el PC.
  3. Esta vez, en la barra de URL, escribe el nombre de dominio: www.miservidor.com y presiona Go.
  4. Si la página web se carga, significa que el servicio DNS tradujo correctamente el nombre a la IP del servidor. ¡Felicidades, tu red está completamente funcional!
